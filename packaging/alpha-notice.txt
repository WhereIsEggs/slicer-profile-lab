Early testing build for Windows x64. Back up your OrcaSlicer profiles before testing.
This installer includes Profile Lab and its Python/Qt runtime; Python setup is not required.
It includes a fixed Orca validator and matching resources for offline checks.
It does not install the Orca GUI or modify your profiles. The editor's system library
can be downloaded separately. No engine setup or nightly download is needed.

Share ZIP packages generated by Profile Lab. Orca re-exported .orca_printer bundles
lost compatibility links in our tests. Review all settings before printing.
The editor and scratch-profile forms are incomplete. Validation is not print certification.

Uninstall removes the application only. Drafts, sets, packages, caches and any Orca
profiles you installed remain intact. Existing Profile Lab workspace data is reused.

This alpha is not code-signed. If Windows or your organization blocks it, do not
disable security controls: ask the publisher/IT for a reviewed distribution route.

See the included testing guide and third-party notices. No telemetry is added.
