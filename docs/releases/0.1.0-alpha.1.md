# Slicer Profile Lab 0.1.0 Alpha 1

First Windows x64 alpha for early testing. This is the real native desktop app,
not a demo. It is experimental and is not a complete replacement for Orca's
settings editor.

## Download

- Install `SlicerProfileLab-0.1.0a1-windows-x64-setup.exe`. Python is included;
  installation is per user and does not require administrator access.
- Matching application/build/dependency sources are supplied in
  `SlicerProfileLab-0.1.0a1-source.zip` under the applicable licenses.
- Read `START-HERE.md` before testing. File hashes are in `SHA256SUMS.txt`.
- The installer is unsigned. If Windows or company policy blocks it, contact
  the publisher or IT; do not disable security protections.

## Included

- Searchable Orca system-profile library with update checking.
- Editable saved drafts and multi-printer profile sets with filament/process
  assignments and defaults.
- Profile validation, package preparation, user-profile installation and
  Profile Lab sharing ZIPs.
- Offline license/source access, AGPL v3 licensing and upstream attribution.

## Important limitations

- Back up Orca profiles first, use unique test names, and close Orca before
  installing profiles. Review settings before printing: validation is not a
  print-safety guarantee.
- Share the ZIP produced by Profile Lab. Orca-re-exported `.orca_printer`
  bundles lost compatibility links in our tests.
- Orca itself, its library and its optional validator are not bundled. The
  library/engine downloads require internet access; incomplete engine setup is
  reported explicitly. The supported system library is pinned to Orca 2.4.2.
- The settings editor, scratch-profile forms and newer dual/flow-variant support
  are incomplete. Wider hardware and clean-Windows-machine testing is needed.
- Uninstalling the app preserves saved work and installed Orca profiles.

Test coverage includes application regression tests, packaged startup and set/ZIP
creation, and an isolated install/reinstall/uninstall cycle on the build machine.
This is not certification of every profile, Windows installation or printer.

Report issues at https://github.com/WhereIsEggs/slicer-profile-lab/issues with your
app/Orca/Windows versions, reproduction steps, and sanitized examples. Do not
upload private profiles or personal information.
