# Slicer Profile Lab 0.1.0 Alpha 2

## Engine setup is now automatic

The Windows installer includes a fixed, tested Orca validator, its required
runtime libraries and matching validation resources. Users no longer need to
install the engine or depend on changing nightly downloads. Validation works
offline; the editor's optional system-library download still requires internet.

The engine is Orca 2.5.0-dev revision f520e9221f220657f752d269ead37dd61e9cb0c3,
not an official released Orca 2.5.0. It does not replace your Orca installation.
Old Profile Lab nightly caches are ignored by this installer. Engine updates
will be delivered with tested Profile Lab releases.

Checks verify bundled file integrity and give a repair message if files are
missing or damaged. Missing user-profile parents are no longer suppressed merely
because the native validator exits successfully; invalid user profiles may be
skipped by upstream, so Profile Lab preserves its own dependency checks.

## Install and test

Help → Check for updates provides a manual GitHub release check and a verified
installer download. No update checks run on startup or on a timer. Downloading
requires a separate click; open the download folder, close Profile Lab and run
setup yourself. Alpha/beta builds include newer previews; stable builds exclude
previews. Only releases with a Windows x64 installer and SHA256SUMS.txt are offered.
Checksums detect corruption; they do not replace Windows publisher signatures.

Download `SlicerProfileLab-0.1.0a2-windows-x64-setup.exe`, close Profile Lab, and
run it. It upgrades the same per-user installation and preserves your saved work.
No administrator access or separate Python setup is required. The installer
remains unsigned; do not disable security protections if installation is blocked.

Back up Orca profiles first and use unique test names. Close Orca before installing
profiles. Try Check my OrcaSlicer profiles while disconnected from the internet.
Read the result: incomplete checks must never be interpreted as a pass.

The complete matching source is `SlicerProfileLab-0.1.0a2-source.zip`, including
Orca and its dependency sources. This is larger than the installer; users need
only the EXE to install. Checksums and START-HERE.md are supplied alongside it.

Remaining alpha limitations still apply: validation does not certify print safety,
the editor is incomplete, and sharing should use Profile Lab's generated ZIP
rather than Orca-re-exported `.orca_printer` bundles. Please test on a clean
Windows computer and report app/Orca/Windows versions with sanitized examples.
